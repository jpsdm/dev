# Metrics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `dev workspace metrics` (alias `dev ws m`) print a per-directory size/project-count table, totals, and the largest project and file in the workspace.

**Architecture:** A new pure-computation package, `internal/metrics`, does one `filepath.WalkDir` pass over the workspace root and returns a `Report` struct — no interactive I/O, no config access, matching `internal/workspace`'s existing separation of concerns. `cmd/workspace.go` gains one new read-only Cobra command that resolves the workspace root the same way every other workspace subcommand does, calls `metrics.Collect`, and renders the result via `text/tabwriter`.

**Tech Stack:** Go stdlib only (`filepath.WalkDir`, `text/tabwriter`) — no new third-party dependency, unlike 3b's `go-git`. This is the smallest of the three workspace sub-projects: one new package, one new command, no destructive operations, no confirmation prompts, no `--dry-run`.

**Spec:** `docs/superpowers/specs/2026-09-27-metrics-design.md`

## Global Constraints

- `internal/metrics` never prompts, reads stdin, or touches `internal/config` — pure computation over an already-resolved root path.
- Size calculation never follows symlinks. This is achieved by relying on `filepath.WalkDir`'s documented behavior (it does not descend into a symlinked directory regardless of its target) — do not add any extra logic that would defeat this (e.g. never call `os.Stat` on a directory entry to "resolve" it before deciding whether to descend).
- `base/`'s `ProjectCount` is exactly `-1` (a sentinel, not `0` and not omitted) — the one directory with no "projects" concept. Every renderer of a `DirStats` must treat `< 0` as "print `-`", not just `== -1` specifically.
- Sizes are formatted binary/1024-based (`KB`/`MB`/`GB`/`TB`), always two decimal places once at least 1024 bytes (`42.00 MB`, never `42 MB`), falling back to a plain `N B` integer count under 1024 bytes.
- `LargestProject` is computed only across `src`/`scratch`/`archive` (not `base`, which has no projects); `LargestFile` is computed across all four directories.
- When multiple projects or files tie for the largest size, the alphabetically-first name/path wins — ties must resolve deterministically, or tests (and real output across repeated runs with unrelated same-size files) would be flaky.
- An empty (freshly-scaffolded, no projects or files yet) workspace produces a complete, valid `Report` — zeroed sizes/counts, `LargestProject`/`LargestFile` at their zero values — never an error.
- No test using `t.Setenv` also calls `t.Parallel()` on itself. No Testify — stdlib `testing` only.
- A test that creates a real symlink must `t.Skipf` gracefully if symlink creation fails in the current environment (matching the established pattern from sub-projects 3a/3b), not fail outright.

## Review Focus

- A symlinked directory inside a project must never have its target's size counted — this is the entire reason the whole feature can claim "never follows symlinks," and only a test that creates a real symlink pointing at something large and proves it's excluded actually pins this — Task 1.
- `base/` must report `-` for its Projects column, not `0` and not a blank cell — a reasonable person reading the table would otherwise wonder whether `base/` genuinely has zero projects or whether the number is just missing — Task 1 (the `-1` sentinel) and Task 2 (the render check).
- An empty workspace must produce `Largest project: (none)` and `Largest file: (none)`, not a panic, an empty string printed raw, or an error — the very first thing a new user sees after `dev workspace` (before creating anything) could be `dev workspace metrics` — Task 1 and Task 2.
- Largest-project/largest-file selection must be deterministic on ties — otherwise the same on-disk state could print a different "largest" project on two consecutive runs, which would look like a bug even though nothing changed — Task 1.
- `dev workspace metrics` must work as the very first command run against a totally unconfigured workspace, going through the same first-use path prompt every other workspace subcommand does — it must not special-case or bypass `resolveWorkspaceRoot` — Task 2.

```go
// Package metrics computes a read-only report on a workspace's size and
// shape: per-directory project counts and sizes, totals, and the
// largest project and file. It never mutates the filesystem and never
// prompts — a pure Collect(root) call, mirroring internal/workspace's
// separation of interactive concerns into the cmd layer.
package metrics

import (
	"fmt"
	"io/fs"
	"os"
	"path/filepath"
	"sort"
	"strings"
)

// dirNames lists the four workspace subdirectories, in the order
// they're reported.
var dirNames = []string{"src", "scratch", "archive", "base"}

// projectDirs are the subdirectories whose immediate children are
// "projects" with a meaningful ProjectCount and that participate in
// LargestProject — base/ is a template, not a collection of projects.
var projectDirs = map[string]bool{"src": true, "scratch": true, "archive": true}

// DirStats is one row of the per-directory table. ProjectCount is -1
// for a directory with no "projects" concept (currently only "base") —
// the sentinel a caller renders as "-" rather than a number.
type DirStats struct {
	Name         string
	ProjectCount int
	Size         int64
}

// LargestProject names the single largest top-level project directory
// across src/, scratch/, and archive/ combined. A zero value (empty
// Name) means the workspace has no projects at all.
type LargestProject struct {
	Name string // e.g. "src/api"
	Size int64
}

// LargestFile names the single largest regular file anywhere in the
// workspace (all four directories). A zero value (empty Path) means
// the workspace has no files at all.
type LargestFile struct {
	Path string // relative to the workspace root, e.g. "archive/old/dist/bundle.js"
	Size int64
}

// Report is everything dev workspace metrics prints.
type Report struct {
	Path           string
	Directories    []DirStats
	TotalSize      int64
	TotalFiles     int
	TotalDirs      int
	LargestProject LargestProject
	LargestFile    LargestFile
}

// Collect walks root (a workspace root, already scaffolded) once and
// returns a complete Report. It never follows symlinks:
// filepath.WalkDir does not descend into a symlinked directory
// regardless of its target, and a symlink's own (non-directory) entry
// contributes only its own on-disk size, the same as any other file.
// An empty or not-yet-populated workspace produces a valid, zeroed
// Report rather than an error.
func Collect(root string) (Report, error) {
	dirSizes := map[string]int64{}
	projectSizes := map[string]int64{}
	var totalFiles, totalDirs int
	var largestFile LargestFile

	err := filepath.WalkDir(root, func(path string, d fs.DirEntry, err error) error {
		if err != nil {
			return err
		}
		if path == root {
			return nil
		}
		rel, relErr := filepath.Rel(root, path)
		if relErr != nil {
			return relErr
		}
		parts := strings.Split(rel, string(filepath.Separator))
		topDir := parts[0]

		if d.IsDir() {
			totalDirs++
			return nil
		}

		totalFiles++
		info, infoErr := d.Info()
		if infoErr != nil {
			return infoErr
		}
		size := info.Size()
		dirSizes[topDir] += size
		if projectDirs[topDir] && len(parts) >= 2 {
			projectKey := topDir + "/" + parts[1]
			projectSizes[projectKey] += size
		}
		if size > largestFile.Size {
			largestFile = LargestFile{Path: rel, Size: size}
		}
		return nil
	})
	if err != nil {
		return Report{}, fmt.Errorf("collecting metrics for %s: %w", root, err)
	}

	directories := make([]DirStats, 0, len(dirNames))
	var totalSize int64
	for _, name := range dirNames {
		count := -1
		if projectDirs[name] {
			count, err = countProjects(filepath.Join(root, name))
			if err != nil {
				return Report{}, err
			}
		}
		size := dirSizes[name]
		totalSize += size
		directories = append(directories, DirStats{Name: name, ProjectCount: count, Size: size})
	}

	projectNames := make([]string, 0, len(projectSizes))
	for key := range projectSizes {
		projectNames = append(projectNames, key)
	}
	sort.Strings(projectNames)
	var largestProject LargestProject
	for i, key := range projectNames {
		size := projectSizes[key]
		if i == 0 || size > largestProject.Size {
			largestProject = LargestProject{Name: key, Size: size}
		}
	}

	return Report{
		Path:           root,
		Directories:    directories,
		TotalSize:      totalSize,
		TotalFiles:     totalFiles,
		TotalDirs:      totalDirs,
		LargestProject: largestProject,
		LargestFile:    largestFile,
	}, nil
}

func countProjects(dir string) (int, error) {
	entries, err := os.ReadDir(dir)
	if err != nil {
		if os.IsNotExist(err) {
			return 0, nil
		}
		return 0, fmt.Errorf("reading %s: %w", dir, err)
	}
	count := 0
	for _, e := range entries {
		if e.IsDir() {
			count++
		}
	}
	return count, nil
}
```

```go
// formatSize renders bytes as a human-readable binary-unit (1024-based)
// string, always with two decimal places once at least 1024 bytes,
// falling back to a plain byte count under that.
func formatSize(bytes int64) string {
	const unit = 1024
	if bytes < unit {
		return fmt.Sprintf("%d B", bytes)
	}
	div, exp := int64(unit), 0
	for n := bytes / unit; n >= unit; n /= unit {
		div *= unit
		exp++
	}
	units := []string{"KB", "MB", "GB", "TB"}
	return fmt.Sprintf("%.2f %s", float64(bytes)/float64(div), units[exp])
}

func printMetricsReport(out io.Writer, root string, report metrics.Report) {
	fmt.Fprintln(out, "Workspace Metrics")
	fmt.Fprintln(out)
	fmt.Fprintln(out, "Path:")
	fmt.Fprintln(out, root)
	fmt.Fprintln(out)

	tw := tabwriter.NewWriter(out, 0, 4, 3, ' ', 0)
	fmt.Fprintln(tw, "Directory\tProjects\tSize")
	for _, d := range report.Directories {
		projects := "-"
		if d.ProjectCount >= 0 {
			projects = strconv.Itoa(d.ProjectCount)
		}
		fmt.Fprintf(tw, "%s\t%s\t%s\n", d.Name, projects, formatSize(d.Size))
	}
	fmt.Fprintln(tw, "\t\t")
	fmt.Fprintf(tw, "Total\t\t%s\n", formatSize(report.TotalSize))
	tw.Flush()

	fmt.Fprintln(out)
	fmt.Fprintf(out, "Files: %d\n", report.TotalFiles)
	fmt.Fprintf(out, "Directories: %d\n", report.TotalDirs)
	if report.LargestProject.Name == "" {
		fmt.Fprintln(out, "Largest project: (none)")
```
